Privacy policy

Clipp Studio · last updated 18 October 2026

Clipp Studio is a private tool used by its operator to publish videos to the operator's own YouTube channels. This page explains what data it accesses through Google and what it does with that data.

What data we access

When a channel is connected through Google sign-in, Clipp Studio receives an OAuth access token and refresh token for that channel, with these permissions:

  • Upload videos to the connected YouTube channel.
  • Read channel and video information, such as titles and IDs, to confirm uploads.
  • Manage comments on the channel's own videos (for example, posting a comment on a newly uploaded video).
  • Read YouTube Analytics for the channel, such as daily views.

How we use it

The data is used only to publish the operator's videos to the operator's own channels and to show the operator how those videos perform. It is not used for advertising, not sold, and not shared with anyone.

Storage and security

Tokens and statistics are stored in a private database on a server controlled by the operator, with access restricted to the operator. Tokens are deleted when a channel is disconnected.

Google API Services

Clipp Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Clipp Studio uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

You can revoke Clipp Studio's access at any time from your Google Account permissions page. After that, the stored tokens no longer work.

Contact

Questions about this policy can be sent to the support email shown on the Google sign-in screen for Clipp Studio.
